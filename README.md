# ML Talks

An open-source, YouTube-style site for browsing talk videos from the major AI conferences. It works well on phones.

**Live site:** https://mkj69.github.io/ml-talks/

## Coverage

| Field | Conferences |
|---|---|
| Machine learning | NeurIPS 2013–, ICML 2017–, ICLR 2018– (orals, spotlights, posters, tutorials, invited talks, workshops, competitions) |
| Computer vision | CVPR 2023–, ICCV 2025, ECCV 2024– |
| NLP | ACL 2017–, EMNLP 2016–, NAACL 2018–, EACL 2021–, Findings 2020– |

The index has about 136k entries, about 68k of them with video.

## How it works

- **ML and CV conferences:** the public metadata JSON from each conference's official virtual site, plus the video each event page embeds or links (SlidesLive, YouTube, Vimeo, Facebook).
- **NLP conferences:** the XML in the [ACL Anthology](https://github.com/acl-org/acl-anthology). Videos are Anthology-hosted mp4 files or SlidesLive links.
- **No video is stored or re-hosted.** YouTube, Vimeo, Facebook and Anthology mp4 videos play in the page. Conferences restrict SlidesLive embeds to their own domains, so SlidesLive talks open on slideslive.com, with the conference page as a fallback. Some talks require signing in on the conference site.
- **Mobile:** single-column feed, sticky player, and installable as an app ("Add to Home Screen"). Saved talks and watch history stay on your device.

## Automatic updates

`.github/workflows/update.yml` runs every Monday:

1. `scraper/build.py` refreshes the official metadata. It crawls only pages that are new, or that had no video and are due for a re-check.
2. The crawl cache (`data/pages/`, `data/listings/`) is committed back to the repo.
3. The index is generated and deployed to GitHub Pages.

## Run locally

```bash
python3 scraper/build.py --conf iclr --year 2024   # one conference-year
python3 scraper/build.py                           # everything (minutes with the cache; safe to interrupt)
./serve.sh                                         # then open http://localhost:8000
```

The crawler uses only the Python standard library. By default it runs 4 workers with a 0.5 s pause after each request, to be gentle on the official sites.

## Data layout

Committed crawl cache:

- `data/pages/<conf>-<year>.json`: per-event scrape results (video ids, thumbnails)
- `data/listings/<conf>-<year>.json`: event-listing scrape results

Generated by `build.py`, not committed:

- `data/manifest.json`: entry and video counts per conference-year
- `data/papers/<conf>-<year>.json`: list data. `vs` is a list of `[source, id]`, with source one of `sl` / `yt` / `vm` / `fb` / `mp4`
- `data/abstracts/<conf>-<year>.json`: abstracts, loaded when a talk page opens
